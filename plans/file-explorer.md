# file-explorer

This repo is planned as a standalone file explorer app for UMRK.

## Direction

The app should be treated as a **DinguxCommander port/integration project**, not as a custom file manager designed from scratch.

## Role in the workspace

- separate repo
- launchable from Jawaka
- app-focused, not launcher-focused

## Why separate

Keeping this app in its own repo preserves Jawaka's focus and matches how similar ecosystems expose a file manager as an app rather than baking it into the launcher core.

## Initial bias

Prefer the smallest path that gets a useful DinguxCommander-style app running inside the UMRK ecosystem over redesigning the whole experience from zero.
